// Preguntas frecuentes

Dudas comunes

¿Cuál es la diferencia entre sitio web y landing page?

Una landing page es una sola página enfocada en una acción, como cotizar o comprar. Un sitio web tiene varias páginas y presenta todo tu negocio.

¿Me ayudan con el dominio?

Sí. Te ayudamos a comprarlo o a conectar el que ya tienes.

¿Puedo hacer cambios después?

Sí. Podemos darte mantenimiento o dejarte una forma sencilla de editar textos.
